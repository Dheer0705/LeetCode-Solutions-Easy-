## About
This repository contains short, well-documented solutions to LeetCode problems, beginning with easy-level problems. Each solution is placed in a language-specific folder and named with the problem number and title when applicable.

## Repository structure
- /python/           — Python solutions
- /java/             — Java solutions
- /cpp/              — C++ solutions
- README.md          — This file

Each solution file is named using the LeetCode problem number and a short slug, e.g. `1-two-sum.py` or `1_TwoSum.java`. Include a brief comment at the top describing complexity and approach.

## How to run / test
1. Clone the repo:
   git clone https://github.com/Dheer0705/LeetCode-Solutions-Easy-.git
2. Navigate to the language folder, run the file with the appropriate interpreter or compile as needed.
   - Python: `python3 <file>.py`
   - Java: `javac <File>.java && java <File>`
   - C++: `g++ <file>.cpp -o prog && ./prog`

(If you prefer, add unit tests or a runner script; I can help add one.)

## Contributing
Contributions are welcome! Preferred workflow:
1. Fork the repo.
2. Create a feature branch: `git checkout -b add/<problem-number>-<language>`
3. Add your solution and include:
   - Problem number and title in filename
   - Brief description and complexity in a comment header
4. Open a pull request describing the changes.

Please follow existing folder structure and naming conventions.
